# 管家

管家是管家工作区里的一张普通卡片，标题栏为金色。它和其他卡片遵守同样的规则（见 [architecture.md](architecture.md)）：一张卡一段对话，坏了或聊太长就归档，再召唤就是一张新卡。你可以直接操作任何卡片，管家只是另一个入口。

## 召唤

主内容区左下角的圆形按钮：有未归档的管家卡就打开它，没有就新建一张。按钮从不启动 Agent、不发送任何消息；第一次使用时在卡片里选择 Agent，列表把本机已安装的排在前面。

## 记忆

工作区固定为 `~/.flat/butler`（开发版同样）。经验存在文件里，不靠某一段会话：

| 文件 | 所有权 |
| --- | --- |
| `AGENTS.md`、`ROLE.md` | Flat 管理，每次启动同步；Agent 打开工作区时读 `AGENTS.md`，它要求先读 `ROLE.md` 和下面三份记忆 |
| `USER.md` | 用户明确的偏好与授权，仅首次创建 |
| `MEMORY.md` | 长期事实和决定，仅首次创建 |
| `STATE.md` | 当前事项与卡片索引，仅首次创建 |
| `notes/` | 按需加载的细节与来源 |

分发的模板只包含 Flat 的使用说明、管家职责、权限边界和记忆规则，不包含任何个人信息。

## 怎么帮你盯着

- **定时汇总**：设置 → 通用 → 管家定时汇总。预设有每天、工作日、每隔几小时，或自定义 cron。到点后管家收到各卡现状（状态、等了多久、你上次说的、最后回复、自上次汇总以来完成或失败了几轮），写一份汇总；写完管家卡排进队列。也可以点"立即汇总"。
- **不被逐个事件唤醒**：其他卡片的完成、失败只被收集，留给下一次汇总。待你确认的请求本来就会排到你面前，管家不转告。
- **回信**：管家（或任何卡片）用 `send_message` 交代任务后，对方这一轮结束时，最终回复摘录会自动送回，不需要轮询。
- **前情提要**：卡片回到你面前时，顶部一行写着你上次说了什么、多久之前、之后谁来过。

## 权限

Flat MCP 核验管家卡（管家工作区、路径、存活的会话及连接代次）后，允许它访问所有卡片；其他 Agent 不继承这个授权。访问不等于代你决定：待确认的权限和表单只能由你在卡片里回答，MCP 没有回答它们的工具。

## 卡片工具

- `list_workspaces()`、`list_harnesses(workspaceId)`：列出工作区和该机器可用的 Agent。
- `create_card(workspaceId, kind, requestId, nickname?)`：新建并启动一张卡，返回 `cardId` / `sessionId`；任务用 `send_message` 另行发送。同一 `requestId` 重试不会重复创建。
- `archive_card(cardId, requestId)`：归档闲置卡片，保留历史；执行或排队中的卡片不能直接归档，不能归档自己。
