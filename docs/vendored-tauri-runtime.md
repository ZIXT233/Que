# Que 的 Tauri 本地补丁说明

## 为什么新增了这么多代码

Que 为修复 Windows 下的运行时崩溃，将 `tauri-runtime-wry` 2.11.4 的源码随项目保存到 `src-tauri/vendor/tauri-runtime-wry`，通过 `src-tauri/Cargo.toml` 中的 `[patch.crates-io]` 替换同名依赖。

Cargo 的路径补丁需要一个可编译的 crate，因此仓库包含了这份依赖的源码、清单、构建脚本和许可证。提交中的数千行新增主要来自上游源码，不代表 Que 自行重写了 Tauri，也不是可以删除的备份。保留源码可以让本机和 CI 使用同一份补丁，无需修改各机器的 Cargo 缓存。

来源为 crates.io 发布的 `tauri-runtime-wry` **2.11.4**，保留原有 MIT 和 Apache-2.0 许可证。后续审阅应以该版本为基准比较，而不是把 vendor 目录的全部内容视为本项目新增逻辑。

## Que 实际修改的范围

以下路径均相对于 `src-tauri/vendor/tauri-runtime-wry`：

| 文件 | 用途 |
| --- | --- |
| `src/lib.rs` | 接入 Windows 主线程所有权管理，调整上下文访问、监视器查询和关闭后的句柄处理 |
| `src/main_thread_context.rs` | 新增线程本地存储、所有者与跨线程句柄，以及 5 个所有权测试 |
| `examples/ownership_lifecycle.rs` | 新增真实运行时生命周期回归示例 |
| `examples/clone_race.rs` | 新增仅使用公开 API 的并发克隆复现示例 |
| `Cargo.toml` | 启用示例自动发现 |
| `QUE-PATCH.md` | 记录补丁实现、范围与验证情况 |

Que 自身的 `Cargo.toml` 和 `Cargo.lock` 将依赖指向这份源码；release 配置也保留调试信息，便于后续定位崩溃。

## 修复什么问题

原版本的运行时上下文会随跨线程句柄一起克隆，其中嵌套的 Tao Windows 事件循环目标包含非原子 `Rc`。即使工作线程不调用窗口操作，仅克隆或释放句柄也可能触碰该引用计数，造成内存损坏。

本地补丁让 Windows 上的实际上下文保存在创建线程的注册表中。跨线程句柄只携带标识、所属线程和原子存活状态；不可跨线程移动的所有者负责失效处理和释放。工作线程保留句柄，不会因此持有或最终销毁该上下文。Windows 上该上下文原有的 `unsafe Send/Sync` 实现也被移除。

所有权修复限定在 Windows；其他平台保留上游的上下文所有权方式。监视器查询改走事件循环消息路径，这部分修改并非仅在 Windows 编译。本补丁不等于完成了 Tauri 全平台线程安全审计。

## 已有验证及边界

2026-09-23 的检查中，所有权单元测试 **5/5**、Que 终端协议测试 **15/15** 通过，前端生产构建通过。

此前记录还包含同源 Windows debug A/B：原版并发克隆复现 **5/5 崩溃**，补丁版 **5/5 通过**；以及真实运行时的正常退出、直接销毁和隔离配置下的 Que 窗口、PTY 测试。详细条件与证据见 [崩溃调查记录](crash-2026-09-23.md) 和 [补丁实现说明](../src-tauri/vendor/tauri-runtime-wry/QUE-PATCH.md)。这些历史结果不应当作每次修改后都重新执行过的验证。

现有证据不证明长时间 release 运行可靠性，也不证明其他平台已经通过回归。原版最小复现的异常码与最初应用崩溃的异常码不同，不能声称复现了同一条故障指令。

## 后续维护和移除

当前优先保证 Que 稳定运行；向 Tauri 上游提交修复另行安排，不是本补丁的使用前提。

- 修改 vendor 时，把实际改动集中在补丁涉及的文件，并同步更新实现说明和相关回归验证。
- 升级 Tauri 时检查 Cargo 最终解析到的 `tauri-runtime-wry` 版本与来源，避免路径补丁未生效，或旧补丁与新依赖不兼容。
- 上游发布覆盖该所有权问题的版本后，先对 Que 验证并发克隆、关闭后句柄、窗口拆分与返回、PTY 输出和退出流程。
- 验证替代版本可用后，在同一次修改中移除 `[patch.crates-io]` 对应项及 vendor 目录，更新锁文件，并记录替代版本与验证结果。

在完成替代验证之前，不应单独删除 vendor 目录，否则当前 Cargo 路径依赖将无法构建。
